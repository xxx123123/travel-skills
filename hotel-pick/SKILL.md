# 酒店选型：五维打分卡（双场景模板）

用户给出目的地后，联网调研候选酒店，按五维模型打分，输出**排名表 + 实付和权益明细 + 购买链接/渠道**。预算和价格分只看目标日期的含税实付；权益单列、只在权益维度计分。

**先判场景，再选模板**：

- **场景A 城市型**（默认）：目的地是城市，行程以市区景点/商务/美食为主 → 用「城市五维权重」（档次淘汰制）。
- **场景B 景区/度假区型**：目的地是具体景区、古镇、度假区、海岛（如乌镇、长白山、大理洱海、亚丁），住宿核心是"离玩的地方近不近、套餐带不带门票" → 用「景区五维权重」（动线30+价格30为主轴，档次不淘汰仅微调，见第三步B）。

## 何时使用

- 用户给出城市（+日期/天数/预算/人数），要求推荐酒店、选型、比价。
- 用户给出景区/度假区/古镇名，问"住哪、景区周边酒店怎么选"。
- 用户要囤大促房券（双11、618、品牌会员日、通兑券），问某城市/景区哪家最值得买。
- 用户问"XX酒店值不值""A还是B选哪个"。

## 第一步：向用户确认（缺项才问，别连环轰炸）

最少需要：**目的地**（城市或景区名）。缺以下任一项时用一次 `question` 工具合并询问：

1. 场景判定：市区游还是景区/度假区住（目的地名含"山/湖/古镇/度假区"时默认景区型，仍需确认）
2. 出行日期/天数（决定加价表和淡旺季；景区型还要问是否节假日/暑期旺季）
3. 预算档位（人均/每晚上限）
4. 档次要求（仅城市型执行双轨淘汰制，见维度2；景区型不问档次或只记偏好——远近优先、档次仅微调）
5. 行程类型：景点暴走 / 度假宅酒店 / 交通枢纽中转 / **景区深度游（早出晚归看日出等）**
6. 特殊需求：双早、行政礼遇、亲子、宠物、含门票/温泉/SPA、自驾与否（景区型关键）

## 第二步：联网调研（并行搜索）

**城市型**至少并行发起 2-4 个搜索：

- `<城市> 酒店 <日期> 价格` （查日历房价基准）
- `<城市> 双11/618/大促 房券 通兑 <活动年份>` （查在售房券）
- 目标候选酒店单店名 + `套餐/优惠`
- 若用户要囤券：`<集团> 通兑 <城市>` （万豪/希尔顿/凯悦/洲际/万达等通兑是否覆盖该城市）

**景区型**搜索组合（并行 3-4 个）：

- `<景区> 周边酒店 排名 推荐 <日期>` （候选池+口碑）
- `<景区> 酒店 门票 套餐 双11/团购` （含门票套餐是景区型核心比价对象）
- 景区所在区域的通兑覆盖：`<集团> 通兑 <景区所在城市/区域>`
- 自驾用户加搜 `<景区> 停车 酒店`；看日出/滑雪等特殊动线加搜对应关键词

候选池来源（按优先级）：在售大促通兑覆盖的本城市/景区门店 > 平台大促单店券（含门票套餐） > 集团官方渠道套餐 > 日历房闪促。每城优先找 3–5 家符合硬条件的候选，尽量覆盖档次、价格和品质轨；可订项不足时照实列出。

**景区型候选池额外规则**：必须覆盖三个位置圈层各至少1家——① 景区内/门口（贵但省时间）② 最近配套城镇（性价比圈）③ 品牌酒店/通兑可约店（履约稳）；含"门票+住宿"打包套餐的候选至少1家。

**渠道优先级**：集团官方小程序（凯悦/万豪/Hilton Honors 等，常含SNP和独立库存）≥ 飞猪/天猫旗舰店 > 携程/美团 > 官网直订。记录每个候选的购买链接或可执行的搜索入口（淘口令、小程序名、URL）。

每笔报价保留来源、带时区的查询时间、适用入住夜晚、币种和计价单位（如含税每间每晚），以及价格和库存各自的核实状态。库存按指定分店、房型、间数和全部入住夜晚核对：`已核实可订`、`待核实`、`不可订`。仅能买券、仅写通兑、或只能付款后看预约库存的，列为待核实线索，不进可订排名；没有核实可订项就直说。只想囤券且还没选日期时可比较券本身，但不保证未来能约到。

## 第三步：五维打分

**总分为五项得分之和**，各项上限分别为 40、25、15、10、10 分。

### 维度1 价格力（0-40分）——按实际支付比价

```
含税实付 = 券或房的标价 − 确定可用的支付优惠 + 目标日期加价 + 未包含的必付税费
权益折算后成本 = 含税实付 − 实际会使用的权益估值（仅供参考）
折扣比例 = 含税实付 / 可比日历房含税实付
```

- **权益价值**：双早按门店价×人数；行政/Happy Hour 按人均200-300；餐饮额度按面值×0.5~1（视限制条款）；不用的权益=0。
- **加价必须加回**：逐晚查加价表，把用户实际入住日期的加价计入。券面"低至X折"通常是平日价。
- 同时列总实付和每间每晚实付；逐夜有差异时展示差额。按同日期、间数、房型和退改口径比价。缺实际加价、税费或可比基准时标待核，价格分暂缺，不给精确总分。

| 折扣率 vs 日历房 | 分 |
|---|---|
| ≤5折 | 40 |
| >5折且≤6.5折 | 32 |
| >6.5折且≤8折 | 22 |
| 8折以上 / 与日历房倒挂 | ≤10 |

### 维度2 档次匹配（0-25分）——双轨制及格线，一票淘汰

**两条及格线（双轨制）**：

- **豪华轨**（默认主轨）：及格线 = **奢华档及以上**。适合用户明确要"豪华/五星级体验"时。
- **品质轨**：及格线 = **中端档及以上**。亚朵、全季、桔子、美居、欢朋等可作为候选；用户另有品牌或档次要求时，以实际要求为准。

| 档 | 品牌示例 | 轨道定位 |
|---|---|---|
| 顶奢 | 丽思卡尔顿、瑞吉、华尔道夫、柏悦、四季 | 豪华轨 |
| **奢华（豪华轨及格线）** | **康莱德、君悦、安达仕、W、半岛、安缦、JW万豪** | 豪华轨 |
| 高端 | 威斯汀、万豪、希尔顿、艾美、香格里拉、洲际、凯悦、凯宾斯基 | 豪华轨（降档区） |
| 中高端 | 喜来登、福朋、嘉华、逸林、万丽、**亚朵S/桔子水晶/漫心/禧玥** | 双轨交界 |
| **中端（品质轨及格线）** | **亚朵、全季、桔子**、美居、欢朋、万枫、智选、锦华、维也纳 | 品质轨 |

**打分规则**：

- 达到用户所选轨道及格线：**25分**。
- 低于所选轨道及格线但在另一轨内（如豪华轨选型里出现中高端店）：低一档且价格省40%+ → 15-18；只省一点 → ≤5。
- **执行规则**：
  - Step1 问清轨道；用户未明确时按"**豪华轨为主、品质轨可接受**"双轨并行——即候选池同时容纳两轨，打分时豪华轨候选按奢华及格线判，品质轨候选（亚朵/全季/桔子）按中端及格线判，**两轨同表排名，由总分决定胜负**，不预设豪华轨必胜。
  - 同分或分差≤3时，优先豪华轨（体验上限更高）；品质轨候选若靠价格力大幅领先（总分高5+），如实推荐品质轨并注明"降档换价"。
  - 一票淘汰只对"低于所选轨道及格线"的候选执行（豪华轨下淘汰中端及格线以下；品质轨下淘汰经济型，如汉庭/尚客优级别）。

### 维度3 权益折算（0-15分）

| 权益估值占含税实付比例 | 分 |
|---|---|
| ≥40%（近乎白送） | 15 |
| 20-40% | 10 |
| <20% | 5 |
| 无早无权益裸价 | 3 |

### 维度4 位置动线（0-10分）

- 景点暴走型：距地铁/核心景点步行≤10分钟=10；打车15分钟内=6；更远=≤4
- 度假宅酒店型：酒店即目的地=10；位置偏反而加分
- 交通枢纽型：距高铁站/机场快线=10
- 方法：把行程各日目的地在地图打点，选通勤总时长最短的；无明确行程时按城市核心区（商圈/地铁换乘站）给分。

### 维度5 履约安全（0-10分）——囤券场景专用

| 项目 | 是 | 否 |
|---|---|---|
| 不约可退+过期自动退 | 4 | 0（一票否决） |
| 目标日期不加价 | 3 | 0 |
| 可拆分入住 | 2 | 1 |
| 独立预约库存/官方渠道 | 1 | 0 |

**硬规则**：已知约不上目标日期的候选直接淘汰；预约库存待核实的房券只列线索，注明查询路径和退改条件。

## 第三步B：景区/度假区型五维打分（场景B专用）

**总分为五项得分之和**，各项上限分别为 30、10、20、30、10 分。

与城市型的差异：**景区动线与价格力是主轴（各30），档次权重压到10**——景区型的第一决策变量是"离景区多近、进出多方便"，酒店是不是中端品牌几乎不影响游玩体验。门票等玩乐权益维持高权重（20）。

### 维度1 价格力（0-30分）

- 使用与城市型相同的含税实付算法，**比价基准换成同圈层、同口径的日历房**。权益估值不抵实付。
- 折扣率折算表沿用城市型（≤5折=30满档按比例折算至30分制）。

### 维度2 档次匹配（0-10分）——仅作微调项，不设一票淘汰

- **景区型默认不按档次淘汰**。档次用于在**动线和价格接近的候选之间**微调；用户明确要求最低档次时，按其要求筛选。
- 打分：
  - 品牌中端及以上（桔子/亚朵/全季/福朋/喜来登等）：**8-10**（中端不再因"降档"扣分，及格即近满分）
  - 无品牌但口碑好的民宿/本土酒店（4.7分+、近期无集中差评）：6-8
  - 经济型或差评集中：≤4
- **执行规则**：只有当两家候选动线分差≤3且价格力分差≤5时，才用档次分打破平局；动线差距大时档次分不得翻盘（动线30分制下单家可差20+，档次10分制理论上无法弥补）。

### 维度3 权益折算（0-20分）——门票是核心权益

| 权益 | 折算 |
|---|---|
| 景区门票/索道/接驳票 | 按门票市价×实际会用的张数（多次入园按次数算） |
| 双早 | 门店价×人数 |
| 温泉/正餐/旅拍等度假权益 | 按市价×可用性 |

| 权益估值占含税实付比例 | 分 |
|---|---|
| ≥40%（门票+餐近乎抵掉房价） | 20 |
| 20-40% | 14 |
| <20% | 7 |
| 无门票无早餐裸价 | 3 |

⚠️ 门票权益必须核对：是否限本人/限一次/需预约/节假日不可用——"送2张门票"但限非旺季工作日的，按0折算。

### 维度4 景区动线（0-30分）——景区型的第一决策维度

先按用户交通方式分型：

**自驾**：
- 酒店有免费停车 + 距景区入口车程≤10分钟 = 27-30
- 车程10-20分钟 = 20-25；20-30分钟 = 12-18；>30分钟 = ≤8

**非自驾（公交/索道/景区大巴）**：
- 步行到景区入口/索道站/接驳车站≤10分钟 = 27-30
- 免费/随叫随接送15分钟内 = 20-25；需打车15-30分钟 = 12-18；需换乘或>30分钟 = ≤8

**加分/减分项**：
- 早出晚归动线（看日出、抢索道早班、首批入园）：距入口步行/车程5分钟内 +3；反之深夜回程无车 −3
- 含免费接驳车到景区/高铁站：+3
- 景区第一排但团队客喧闹、停车难：−2（仅小幅扣，不喧宾夺主）
- 位置圈层说明：圈层本身不加分，**动线效率**才是得分来源——"景区门口的差评民宿"可能输给"城镇里车程5分钟的品质酒店"；但同为差评边缘时，近者优先。

**动线主导原则**：动线分差是本模型最大分差来源。当两家候选动线分差≥8时，除非低动线方价格力或权益有≥10分的补偿，否则高动线方直接胜出——这就是"离景区远近优先"的落地规则。

### 维度5 履约安全（0-10分）

与城市型同表，另加两条景区型专属检查：

| 项目 | 是 | 否 |
|---|---|---|
| 旺季（节假日/暑期）预约池充足、非"限量N间" | +2 | 0 |
| 门票套餐的门票可预约到目标日期 | +2 | 0（一票否决） |

**景区型硬规则**：① 推荐可订的含门票套餐前，同时核实住宿和门票目标日库存；② 核对不可用日期和旺季加价；③ 民宿类候选查近期差评（卫生、照骗、临时涨价）。景区专属加分后履约安全仍以 10 分封顶。

## 第四步：输出格式

**城市型**：

```markdown
## <城市> 酒店选型（<日期/天数>）

| 排名 | 酒店 | 档次 | 每间每晚含税实付 | 可比日历价 | 折扣 | 总分 | 关键理由 |
|---|---|---|---|---|---|---|---|

### 🥇 首选：<酒店名>
- 实付明细：标价 X − 优惠 Y + 加价 Z + 未含税费 = **N/晚**；权益估值 W、折算后成本另列
- 购买渠道：<链接 / 淘口令 / 小程序名>
- 价格和库存：<来源、查询时间、适用夜晚、核实状态>；预约与退改：<规则、有效期>
- 避坑提示：<加价表陷阱、约满风险、旺季库存等>

### 备选说明
- <次选>：输给首选的维度是X（<具体分差>）
- <价格锚>：若用户更看重绝对低价的替代方案
```

**景区/度假区型**（列结构有差异）：

```markdown
## <景区> 周边酒店选型（<日期/天数> · 自驾/非自驾）

| 排名 | 酒店 | 位置圈层 | 档次 | 门票套餐 | 每间每晚含税实付 | 景区动线 | 总分 |
|---|---|---|---|---|---|---|---|

### 🥇 首选：<酒店名>
- 实付明细：<同城市型，门票权益单列>
- 景区动线：<距入口/索道车程或步行时间、停车、接驳>
- 门票核对：<门票市价、限次规则、能否约到目标日>
- 购买渠道 / 预约与退改 / 避坑提示 <同城市型>

### 圈层对照说明
- 圈层①景区门口：贵X元但省Y分钟
- 圈层②配套城镇：便宜X元，车程Y分钟
- 圈层③通兑可约店：履约最稳
```

**必给购买链接**：能拿到 URL 的给 URL；只有淘口令的给口令+短链；只有小程序的给出小程序名称和搜索路径；都没有的给出明确的平台搜索词。注明链接可能过期、以实时页面为准。

## 红线与提醒

- 二手平台"品牌方送的房券/代订"一律标记为风险，建议走官方渠道（酒店已多次声明未授权闲鱼等渠道）。
- 对房券提示下单前核对目标日期、加价、预约和退款条款。仅在查到活动规则后把叠券计入实付。
- 价格必须标注"以实时页面为准"，不编造精确价格；搜索不到的信息明确说"未查到"，用合理区间代替。

## 示例（结构参考）

**城市型·算价示例**：某房券含税实付 ¥799/晚，确实会使用的权益估值 ¥300，折算后成本 ¥499。预算上限 ¥750 时，该券超预算；即使预算足够，若可比日历房实付 ¥1,000，价格分也按约 8 折算，¥300 只计权益分。若目标夜晚库存没核到，仍只列为待核实线索。

**景区型·思路示例**（按动线主导的30分制）：A=景区门口民宿 800/晚无门票、动线29但差评风险（履约/档次分被压）；B=城镇品牌酒店 500/晚含双早+景区接驳、动线23；C=车程25分钟的度假酒店 600/晚含2张门票（门票市价190×2）、动线10 → C门票权益再厚（+10分级）也补不回13分的动线差距，A或B胜出；A与B动线差6分，若A差评集中导致履约−3、档次只有6分，B反超。落地规则：**动线分差≥8时，除非低动线方价格+权益合计多10分以上，否则高动线方直接赢**；档次分只在动线接近时才起作用。
