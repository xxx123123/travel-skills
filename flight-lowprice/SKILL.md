# 国内低价机票发现

先用携程含税日历价筛选目的地，再为用户选中的目的地查往返与具体航班。脚本查询的是 1 位成人的单程缓存价；当前舱位、航班、行李和退改均以实时选票页为准。

## 确定输入和日期

- 沿用已给出的出发地、日期、机场、区域和预算。出发城市或出行时段缺失且无法推断时，一次问齐。发现目的地时，未指明的预算默认按每位成人单程含税价，输出时注明；用户说“往返”“来回”就按两程含税合计。
- 普通周末默认按周五出发、同一周日返回；若用户只能周六出发、希望更灵活或指定停留晚数，按其要求生成备选。处理多个周末时保留各自的去回日期配对，不将不同周末的最低价拼成短途往返。排除已过的出发日。
- 节假日查对应年份的国务院办公厅放假通知，核对调休；默认考虑假期首日及前一日出发、假期末日或用户能接受的日期返回。将相对时间展开成具体日期，简要说明口径后继续查价。

## 第一阶段：查低价目的地

用携程城市码查询（例如上海 SHA、北京 BJS）。通过本 skill 目录运行脚本，使用 Python 3，无第三方依赖：

```text
python scripts/lowprice.py --from <出发码> --dates <逗号分隔的去程日期> --group-by-region --json
```

- 默认扫描内置国内目的地池；用 `--region 东北,西南` 之类的参数缩小范围。支持东北、华北、华东、华中、华南、西南、西北；区域和海岛、山岳、古城、都市等旅行类别分开。指定少数候选时用 `--dests` 替换默认池；用 `--add-dests` 补充、`--exclude-dests` 排除。池外且未归类的点名城市单独查询，不用区域参数将其静默排除。
- 单程“低于 ¥800”用 `--under-price 800`，“¥800 以内（含 ¥800）”用 `--max-price 800`。筛的是含税总价，先筛后排序；如需逐日选价，加 `--by-date`。往返预算先用去程缩小候选，再查返程并按有效日期组合的两程合计筛；返程缺价时不能判为达标。若用户明确要查某城市，即使超预算或没报价也单列原因。
- 默认先给全局最低或最值得看的少数选项，再按区域展示；每个区域内按单程含税价升序，列目的地、价格、出发日期和携程航线链接。区域很多时可以每区先显示最便宜的几条，并注明尚有多少条；除非用户明确要全国前 N，否则分区时不要在脚本里用全局 `--top`，以免便宜的少数区域挤掉其他区域。
- 标注“含税日历价，以实时页面为准”和查询时间。日历价按城市查询，上海市价可能来自虹桥或浦东；要求特定机场时核对对应日期、机场和报价，未核到则标为全市参考价。直飞、红眼、中转和折扣也只在有对应证据时标注。
- 报告查询覆盖和筛选结果。JSON 的 `checked`、`quoted`、`matched` 分别是查询数、有报价数、截取展示前的达标数，`errors` 区分无日历报价与请求失败。若无达标票，区分有报价但超预算和没有报价；超预算可另给最近的一档并明确标记，不混入达标榜。缺价不表示没有航班。
- 接口不可用、无结果或用户关心的航线未报价时，改查携程、去哪儿、同程等平台对应日期的航线页或低价聚合页。区分实时可查价格与聚合参考价；搜索不到同口径价格就明示，别补成完整榜单。

## 第二阶段：查选中目的地的往返

对每个选中的城市分别查去程和返程。传入所有可行候选日期；返程交换出发、到达码：

```text
python scripts/lowprice.py --from <出发码> --dests <目的地码> --dates <候选去程日期> --by-date --json
python scripts/lowprice.py --from <目的地码> --dests <出发码> --dates <候选返程日期> --by-date --json
```

用 `routes[].prices` 中的逐日含税价，只给符合已确定窗口和晚数的去回组合求和。有往返预算时，按组合合计筛选，再在达标组合中排序。优先呈现最低的可行组合，可加一个时间更合适的备选。两张单程日历价的合计是估算；缺一程就标明缺价并查对应日期的航班页，不报往返合计。若用户只需单程，跳过返程。

在对应日期的航班列表或航司页面核对航司、机场、起降时间、是否直飞或中转、是否红眼；如有可核实的促销、行李或退改信息，注明适用的航班、舱位和来源。一般时刻表只作线索；未核到具体舱位时注明退改待选票确认。

给出推荐日期、两程含税日历价及合计、已核实的航班信息和携程选票链接。优先使用能定位日期的已核实页面；否则使用携程公开航线查询页 `https://flights.ctrip.com/booking/<出发码大写>-<目的地码大写>-day-1.html`，例如上海至三亚为 `https://flights.ctrip.com/booking/SHA-SYX-day-1.html`。航线页未预填日期时写明要选的日期；需要两程时可分别给去程和返程链接。由用户在页面核价下单。需要住宿时可接 `hotel-pick`。
