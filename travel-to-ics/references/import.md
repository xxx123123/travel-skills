# 导入和排查

建议导入独立的旅行日历。完成后核对一条关键时间和提醒；客户端可能不保留文件里的提醒。再次导入前先检查目标日历，稳定 UID 不保证每个客户端都能去重。

| 用户的情况 | 路线 |
| --- | --- |
| iPhone 自带「邮件」能收到附件 | 在「邮件」打开 .ics，有添加入口时选择目标日历。 |
| 只能用 QQ 邮箱，或「文件」只预览、没有添加入口 | 在 QQ 邮箱把 .ics 存到「文件」。仅用手机时，可使用支持从分享菜单批量导入的日历工具，例如国区 App Store 的 ICS2Calendar（第三方，可能收费）；预览日程后选择目标日历。不愿安装 App 就走电脑路线。 |
| Windows 或其他电脑，能使用 Outlook 网页版 | 日历 → 添加日历 → 从文件上传，选 .ics 和目标日历。iPhone 日历账户添加同一 Outlook 账号并打开日历同步。日程保存在 Outlook 账号，可在苹果「日历」显示。 |
| Mac，想把日程存在 iCloud | Mac「日历」→ 文件 → 导入，选择 .ics 和 iCloud 下的目标日历；iPhone 使用同一 iCloud 账号并启用日历。 |
| 已使用 Google 日历 | 在电脑端 Google 日历的设置中选择「导入和导出」，导入 .ics 到指定日历；iPhone 添加同一 Google 账号并启用日历。 |

排查时先区分：**没有导入入口、预览找不到日程、已导入但看不到、或时刻和提醒不对**。仅预览不能说明文件坏了。导入后看不到，先检查日历是否勾选，再跳到旅程日期。不要把本地文件当作订阅 URL，也不要要求用户公开旅行文件。

参考：[Apple iPhone 日历账户](https://support.apple.com/zh-cn/guide/iphone/ipha0d932e96/ios)、[Apple Mac 日历导入](https://support.apple.com/zh-cn/guide/calendar/icl1023/mac)、[Outlook 文件导入](https://support.microsoft.com/zh-cn/outlook/import-or-subscribe-to-a-calendar-in-outlook-com-or-outlook-on-the-web)、[Google 日历导入](https://support.google.com/calendar/answer/37118?hl=zh-Hans)、[ICS2Calendar 产品页](https://apps.apple.com/cn/app/ics2calendar/id6742157560)。
